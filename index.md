# Documentación APS-Conecta

Esta documentación cubre la suite APS Conecta Gestión: la intranet operativa autoalojada para la atención primaria de salud chilena, con una instalación por establecimiento y sin datos de pacientes. El sitio se organiza por audiencia — personal del centro de salud, administración y desarrollo — y cada árbol reproduce la estructura del manual correspondiente.
