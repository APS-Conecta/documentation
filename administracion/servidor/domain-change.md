# Cambio de dominio

## Resumen

Esta página explica, para quienes administran el servidor, que Nextcloud no admite por ahora cambiar el dominio después de la primera configuración, y el motivo principal.

````{upstream} admin_manual/configuration_server/domain_change.rst@3ad91587229242efe4502ce61aed9c0f1154bd5e
Actualmente, Nextcloud no admite cambiar el dominio después de la primera configuración. Esto se debe principalmente a que las apps de Nextcloud no admiten un cambio de dominio una vez configuradas.

:::{note}
Esta documentación se actualizará con los pasos que hay que seguir para cambiar el dominio en cuanto esta función esté disponible.
:::
````
