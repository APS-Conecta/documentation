# API OCS de procesamiento de tareas

## Resumen

Esta página presenta, para quienes desarrollan clientes o apps, la API OCS de procesamiento de tareas, que ejecuta tareas implementadas por apps mediante la API de procesamiento de tareas del backend, y remite a su documentación OpenAPI.

````{upstream} developer_manual/client_apis/OCS/ocs-taskprocessing-api.rst@3ad91587229242efe4502ce61aed9c0f1154bd5e

:::{versionadded} 30.0.0
:::

La API OCS de procesamiento de tareas permite ejecutar tareas de procesamiento de tareas, como enviar instrucciones a modelos de lenguaje grandes, que implementan apps mediante {nc-ref}`la API de procesamiento de tareas del backend <task_processing>`.

Ver la [documentación OpenAPI](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html#/operations/core-task_processing_api-schedule) correspondiente.
````
