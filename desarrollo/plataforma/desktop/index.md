# Clientes de escritorio

## Resumen

Esta sección presenta el cliente de sincronización de escritorio, disponible para Windows, macOS y varias distribuciones de Linux, y reúne la documentación para compilarlo. Está dirigida a desarrolladores que quieran compilar el cliente por su cuenta.

````{upstream} developer_manual/desktop/index.rst@3ad91587229242efe4502ce61aed9c0f1154bd5e
Disponible para Windows, macOS y varias distribuciones de Linux, el cliente de sincronización Nextcloud Desktop permite:

- Especificar uno o más directorios del equipo que se quieren sincronizar con el servidor Nextcloud.
- Tener siempre sincronizados los archivos más recientes, estén donde estén.

Esta documentación está dirigida a desarrolladores que quieran compilar el cliente por su cuenta.
````
