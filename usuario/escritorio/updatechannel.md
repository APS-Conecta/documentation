# Canales de actualización

## Resumen

Esta página describe los cuatro canales de actualización del cliente de escritorio, a quién está destinado cada uno y dónde se publican sus versiones. Está dirigida a usuarios que eligen de qué canal recibir las actualizaciones del cliente.

````{upstream} user_manual/desktop/updatechannel.rst@3ad91587229242efe4502ce61aed9c0f1154bd5e
Tanto si se desean las últimas funciones, como si se quiere ayudar con las pruebas o simplemente esperar a que todo esté perfectamente listo, tenemos opciones para cada caso.

El cliente de escritorio tiene 4 canales de actualización: *Enterprise*, *Stable*, *Beta* y *Daily*.

:::{list-table} Canales
* - Enterprise
  - Versión especial para clientes empresariales, para la mejor experiencia posible.
* - Stable
  - Últimas versiones con nuevas funciones, listas para la mayoría de los usuarios con un riesgo mínimo.
* - Beta
  - Versiones de corta duración creadas como preparación para que los probadores informen de errores antes de una versión estable.
* - Daily
  - Versiones diarias para reproducir errores y seguir el desarrollo de la próxima versión estable.
:::
````
