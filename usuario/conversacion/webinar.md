# Seminario web y sala de espera

## Resumen

Esta página explica a los moderadores de Talk para qué sirve la sala de espera, de qué formas pueden entrar los participantes a la llamada y en qué sección de los ajustes de la conversación se configura.

````{upstream} user_manual/talk/webinar.rst@3ad91587229242efe4502ce61aed9c0f1154bd5e
La función de sala de espera permite mostrar a los invitados una pantalla de espera hasta que empieza la llamada. Es ideal, por ejemplo, para seminarios web con participantes externos.

Se puede elegir que los participantes se unan a la llamada a una hora determinada, o cuando se retire manualmente la sala de espera.

La sala de espera se configura en `Conversation settings`, en la sección `Webinar`.
````
