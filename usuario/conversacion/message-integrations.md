# Aplicaciones que se integran con los mensajes

## Resumen

Esta página explica a las personas usuarias cómo las aplicaciones se integran con los mensajes de Talk, con el caso de Deck: crear una tarjeta a partir de un mensaje del chat y compartir una tarjeta en un chat.

````{upstream} user_manual/talk/message_integrations.rst@3ad91587229242efe4502ce61aed9c0f1154bd5e
Varias aplicaciones se integran con los mensajes de Talk y permiten convertir mensajes en elementos accionables o compartir contenido directamente en las conversaciones.

### Deck

#### Crear tareas a partir de un mensaje del chat

Si Deck está instalado, se puede usar el menú `...` de un mensaje del chat para convertir el mensaje en una tarjeta de Deck.

#### Compartir una tarjeta en un chat

Desde Deck se pueden compartir tarjetas en un chat.
````
