# Organizar conversaciones

## Resumen

Esta página explica a las personas usuarias de Talk cómo clasificar sus conversaciones con etiquetas y cómo ordenar y agrupar la lista de conversaciones.

````{upstream} user_manual/talk/conversation_organization.rst@3ad91587229242efe4502ce61aed9c0f1154bd5e
Nextcloud Talk ofrece funciones para organizar y gestionar las conversaciones de forma eficiente.

### Etiquetas

Crear etiquetas personalizadas para clasificar las conversaciones y mantenerlas organizadas. Las etiquetas ayudan a agrupar las conversaciones por proyecto, equipo, tema o cualquier otro criterio que tenga sentido para la propia forma de trabajar.

1. Seleccionar una conversación y abrir el menú de acciones
2. Seleccionar `Tags` y elegir una etiqueta existente o crear una nueva
3. La conversación queda etiquetada y agrupada en consecuencia

Más adelante se pueden gestionar las etiquetas existentes: renombrarlas, reordenarlas o eliminarlas.

### Ordenar y agrupar

Además, se puede personalizar cómo aparecen las conversaciones en la lista. Se pueden ordenar:

- **Por última actividad**: mostrar primero las conversaciones con actividad más reciente (predeterminado)
- **Alfabéticamente**: ordenar las conversaciones alfabéticamente por nombre

Los tipos similares también se pueden agrupar:

- **No agrupar por tipo**: mantener una lista plana de todas las conversaciones
- **Mostrar primero las privadas**: mostrar las conversaciones privadas antes que las de grupo o públicas
- **Mostrar primero las de grupo**: mostrar las conversaciones de grupo o públicas antes que las privadas
````
