# Integración con Archivos

## Resumen

Esta página explica a las personas usuarias cómo conversar sobre un archivo desde la barra lateral de la aplicación Archivos, incluso en una llamada mientras se edita, y cómo volver al archivo desde la conversación que Talk crea para él.

````{upstream} user_manual/talk/files_integration.rst@3ad91587229242efe4502ce61aed9c0f1154bd5e
### Talk desde Archivos

En la aplicación Archivos se puede conversar sobre los archivos en la barra lateral, e incluso mantener una llamada mientras se edita el archivo. Primero hay que unirse al chat.

Después se puede chatear o mantener una llamada con otros participantes, incluso al empezar a editar el archivo.

En Talk se creará una conversación para el archivo. Se puede chatear desde ahí, o volver al archivo con el menú `...` de la parte superior de la conversación.
````
