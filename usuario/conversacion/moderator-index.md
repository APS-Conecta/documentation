# Para moderadores

## Resumen

Esta página presenta a los moderadores de Talk lo que su rol permite hacer y dónde se describen las acciones exclusivas de moderación dentro de las conversaciones y las llamadas.

````{upstream} user_manual/talk/moderator_index.rst@3ad91587229242efe4502ce61aed9c0f1154bd5e
Como moderador se pueden crear y configurar conversaciones, gestionar participantes, realizar seminarios web con sala de espera, grabar llamadas, configurar salas de grupos e integrar servicios de chat externos.

:::{note}
Las acciones exclusivas de los moderadores dentro de las conversaciones y las llamadas también se describen en las páginas generales {nc-doc}`Conversaciones <user_manual/talk/conversations>` y {nc-doc}`Llamadas <user_manual/talk/call>`: buscar las secciones marcadas como *moderador*.
:::
````
