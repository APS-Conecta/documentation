# Adjuntos

## Resumen

Esta página explica cómo compartir archivos en un chat de Talk y cómo crear, importar, exportar, cerrar y guardar como borrador encuestas en los chats grupales. Está dirigida a quienes participan en conversaciones de Talk.

````{upstream} user_manual/talk/attachments.rst@3ad91587229242efe4502ce61aed9c0f1154bd5e
### Compartir archivos en un chat

Hay tres maneras de compartir archivos en un chat.

Primero, simplemente se pueden arrastrar y soltar en el chat.

Segundo, se puede seleccionar un archivo de Nextcloud Files o de un gestor de archivos eligiendo el pequeño clip y seleccionando desde dónde se quiere tomar el archivo.

Se pueden agregar más archivos hasta terminar y decidir compartirlos. También se puede agregar una leyenda de texto a los archivos compartidos, con una breve descripción o contexto.

Todos los usuarios podrán hacer clic en los archivos para verlos, editarlos o descargarlos, tengan o no una cuenta de Nextcloud. A los usuarios con cuenta se les comparte el archivo automáticamente, mientras que a los usuarios invitados externos se les comparte como enlace público.

### Encuestas en el chat

Se puede crear una encuesta en los chats grupales desde las acciones adicionales del mensaje nuevo.

Una encuesta tiene dos ajustes:

- **Encuestas anónimas**: los participantes no pueden ver quién votó por cada opción.
- **Permitir varias opciones**: los participantes pueden seleccionar más de una opción.

También se pueden importar encuestas para rellenarlas automáticamente y exportar encuestas como archivos JSON para guardarlas localmente.

Una encuesta se puede cerrar desde el diálogo de la encuesta.

Como moderador, se puede crear la encuesta directamente o guardarla como borrador para editarla más tarde.

Los borradores de encuestas se encuentran en la pestaña {guilabel}`Elementos compartidos` o junto al campo de entrada del título de la encuesta.
````
