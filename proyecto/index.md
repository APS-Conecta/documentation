# Proyecto

El proyecto mantiene la suite, sus aplicaciones y esta documentación como una organización en GitHub: repositorios propios bajo AGPL, incidencias tipadas como registro público de errores y tareas, y una hoja de ruta visible. Esta sección reúne el catálogo de repositorios de la organización, las novedades de cada aplicación, los errores conocidos, las tareas pendientes y la hoja de ruta del proyecto.
